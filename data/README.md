# Research Data

The complete computational and experimental datasets associated with this
study are archived in Zenodo.

The deposited data include:

- virtual-screening and compound-prioritization results;
- molecular-docking inputs and outputs;
- molecular-dynamics inputs, trajectories, and analysis outputs;
- MM/PBSA input and output files;
- PCA and free-energy-landscape data;
- ADME and similarity-analysis results;
- biochemical CETP assay measurements;
- source data underlying the manuscript figures and tables.

**Zenodo dataset DOI:** To be added after deposition.

The data are not duplicated in this GitHub repository to avoid version
ambiguity and unnecessary storage of large scientific files.
