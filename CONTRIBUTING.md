# Contributing

This repository accompanies a published research article and is primarily maintained for reproducibility of the reported results. That said, contributions are welcome:

- **Bug reports / questions** — please open a GitHub Issue describing the problem, the script/stage involved, and your environment (OS, conda/pip versions).
- **Pull requests** — for fixes or extensions (e.g., new descriptors for clustering, alternative docking backends), please open an issue first to discuss scope before submitting a PR.
- **Code style** — keep new scripts consistent with the existing folder-per-stage structure (`scripts/0N_stage_name/`) and include a short docstring describing inputs/outputs.

For questions about the underlying methodology, contact the corresponding author listed in the README.
